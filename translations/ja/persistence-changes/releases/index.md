## ファイルと範囲

各タグには、`kind: persistence-release` を持つ英語／中国語の記録、ペアリング用のサイドカー、`.schema.json` がある。その機械宣言には、タグ、直前の前身、観測されたライター・バージョン、各変更ルートの before/after ダイジェストが含まれる。最初のスナップショットはすべてのルートを含み、後のスナップショットは、存在し続ける変更済みルートとその到達可能なすべての型だけを保持する。削除は after の値に null を使う。変更のないリリースは空の changes とスナップショットを保持する。

スナップショットは、論理的な Session ヘッダー、物理的な JSONL ヘッダー、イベント・エンベロープ、およびそのタグにおけるすべてのファーストパーティのイベントと推移的な参照を対象とする。型の数には、正規化後に到達可能な定義だけを含める。履歴のソース参照は、行番号なしのファイル・パスを保持する。

これらの回顧的な記録は、親ディレクトリの現在の承認チェーンとは別に検証される。古い変更に対する現在のルールの分類は読解の助けである。歴史的なバージョン 0 には、バージョンを上げずに構造上の変更が含まれていた。バックフィルされた記録は、現在の PR が承認や必要なバージョン引き上げを省略することを認可できない。

<a id="extraction"></a>
## 抽出と制限

再構成には、各タグのソース、TypeScript 6.0.3、マージ済みの[スキーマ抽出器](https://github.com/deepseek-ai/deepseek-harness/blob/master/scripts/persistence-schema.ts)を使った。唯一の抽出上の適応は、初期の具象イベント・レコードの交差型から冗長な `object` メンバーを省略することである。既存の `any` / `unknown` は不透明のまま残し、未解決の参照に対して追加の不透明型を代入することはなかった。リリース・スキーマ JSON は履歴の識別子を保持する。用語のチェックは、著作された記録と現在のスキーマに引き続き適用される。

最初の 22 個のタグは、サーフェス・イベントでオプショナルの `surfaceOp` を正当に宣言している。履歴のパースはそのオプショナル性を保ち、現在のソースのパースは引き続きそのフィールドを必須とする。以前の `SessionHeader.version: number` 宣言もそのまま残り、実際のライター・バージョン定数は別に記録される。広い `number` 宣言はその定数を提供できない。

取得したタグはライター・バージョン 0、2、3 を使用し、バージョン 1 を使うタグはない。

ダイジェストは正規化された再構成後の型を表し、ソース・テキストの逐語的な内容や元のツールチェーンの再現ではない。要約はおおよその構造的コンテキストを提供する。古いアプリケーションは再生されておらず、codec の完全な挙動は検証されておらず、移行の安全性も証明されていない。変更されていないダイジェストは、挙動が変わっていないことを確立しない。

<a id="verification"></a>
## 検証

26 個のスナップショットはすべて、正規グラフ、ルート・ダイジェスト、到達可能な型のダイジェストの検証に合格した。リリース・アーカイブのチェックは、Git、ネットワーク・アクセス、旧バージョンのチェックアウトを使わず、このツリー内のマニフェスト、記録、スナップショットだけを読む。マニフェストの網羅性、前身、before/after の値、スナップショットの型の完全性、バイリンガルの機械宣言を検証する。

```sh
pnpm run verify-persistence-releases
pnpm run doc-sync
```

マーカーで区切られた索引、インベントリーのセル、構造変更の事実は、スナップショットから生成される。既定の検証は古くなった事実を拒否する。すべての機械データを検証した後にそれらの領域とペアリング記録を更新するには、`pnpm run verify-persistence-releases --write` を実行する。著作された要約、ソース・エビデンス、機械宣言、スキーマ・ファイルは保持される。

タグの完全性は、マニフェストが取得した範囲に対して相対的である。オフラインのチェックは、後のタグを自動的に発見しない。標準のドキュメント・チェックは、ペアリング記録と Markdown リンクを検証する。[形式テンプレート](https://github.com/deepseek-ai/deepseek-harness/blob/master/.agents/skills/dsh-doc/templates/persistence-release.md)が各記録のフィールドを定義する。
